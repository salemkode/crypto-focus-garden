# Expo rebuild, 17 November 2026 (from `salemkode/focus-garden-next`)

Before the app moved into `packages/mobile` here, it was rebuilt as a standalone Expo app in
[`salemkode/focus-garden-next`](https://github.com/salemkode/focus-garden-next) (PR #1,
`feat/expo-rebuild`). That rebuild's code was consolidated into this repository on 18 November
(`c7b2e1c`, "Add the Expo app, Focus Forest contracts and garden service") and has changed a lot
since then: the garden service is gone, the app runs on Mainnet, and the web platform shims were
folded into `packages/mobile`.

This folder keeps that rebuild's documentation and evidence screenshots as a historical record. They
describe the rebuild at the time, not the current app. The rebuild branch itself is merged into this
repository's history, so its full commit history is available with `git log`.
